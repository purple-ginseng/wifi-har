# wifi-har

Landing page for the WiFi-based human activity recognition project.

- Live page: <https://purple-ginseng.github.io/wifi-har/bfmsensing/>
- Source code: <https://github.com/purple-ginseng/WiFi-Signal-Processing-HAR-POC>

The page in `bfmsensing/` is a static trailer/showcase. It references the
project figures bundled alongside it (`plots/` and the per-environment result
PNGs at the repo root) so the site is fully self-contained.
